# План: Миграция с HTTP Basic Auth на JWT

## Цели
Заменить HTTP Basic авторизацию на JWT-токены (Bearer token). Добавить endpoint для получения токена.

## Архитектура

```
Клиент                    Приложение
  |                         |
  |-- POST /auth/login ---->|
  |                         |-- Валидация credentials
  |                         |-- Генерация JWT
  |<-- { "token": "..." } --|
  |                         |
  |-- GET /hello -----------|
  |   Authorization: Bearer <token>
  |                         |-- Валидация JWT через фильтр
  |                         |-- Установка SecurityContext
  |<-- "Привет, admin!" ----|
```

## Шаги реализации

### 1. Добавить зависимость JWT в `build.gradle`
- `io.jsonwebtoken:jjwt-api:0.12.6` (API)
- `io.jsonwebtoken:jjwt-impl:0.12.6` (impl, runtime)
- `io.jsonwebtoken:jjwt-jackson:0.12.6` (JSON parser, runtime)

### 2. Создать `JwtService.java` (`src/main/java/com/example/demo/JwtService.java`)
- Константы: `SECRET_KEY` (hardcoded для простоты), `EXPIRATION_MS = 86400000` (24 часа)
- Метод `generateToken(String username)` — создаёт JWT с claim `sub = username`
- Метод `validateToken(String token)` — возвращает boolean
- Метод `extractUsername(String token)` — возвращает username из токена

### 3. Создать `JwtAuthenticationFilter.java` (`src/main/java/com/example/demo/JwtAuthenticationFilter.java`)
- Наследуется от `OncePerRequestFilter`
- Извлекает `Authorization` header, проверяет префикс `Bearer `
- Вызывает `JwtService.validateToken(token)`
- Если валиден — создаёт `UsernamePasswordAuthenticationToken` и устанавливает в `SecurityContext`

### 4. Обновить `SecurityConfig.java`
- Удалить `httpBasic()`
- Добавить `.csrf(csrf -> csrf.disable())` (stateless API)
- Добавить `.addFilterBefore(new JwtAuthenticationFilter(jwtService), UsernamePasswordAuthenticationFilter.class)`
- Настроить `.authorizeHttpRequests` — оставить `anyRequest().authenticated()`

### 5. Обновить `App.java`
- Добавить endpoint `POST /auth/login` с body `{ "username": "...", "password": "..." }`
- DTO класс `LoginRequest` (username + password)
- Валидация через `UserDetailsService`
- При успехе — вернуть `{ "token": "..." }`
- При ошибке — 401

### 6. Обновить тест `SecurityIntegrationTest.java`
- `testHelloWithoutAuth` — 401 (без токена)
- `testHelloWithCorrectAuth` — получить токен через `/auth/login`, затем использовать Bearer token
- `testHelloWithWrongAuth` — 401 (невалидный токен)
- Удалить тест с wrong password (тестировать только валидацию токена)

- `src/main/java/com/example/demo/App.java` — добавить login endpoint
- `src/test/java/com/example/demo/SecurityIntegrationTest.java` — обновить тесты

- `src/main/java/com/example/demo/JwtService.java`

## Верификация
1. `.\gradlew test` — все тесты проходят
2. `.\gradlew bootRun` — приложение стартует
3. Тест curl:
   ```
   curl -X POST http://localhost:8080/auth/login -d '{"username":"admin","password":"123"}'
   curl -H "Authorization: Bearer <token>" http://localhost:8080/hello
   ```
